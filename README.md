# mos-vic-ii

The MOS VIC-II video chip family, including the C128's VIC-IIe.

| Crate | Registry |
|---|---|
| [`emu198x-mos-vic-ii`](crates/emu198x-mos-vic-ii) | [crates.io](https://crates.io/crates/emu198x-mos-vic-ii) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Commodore 64 and 128.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
